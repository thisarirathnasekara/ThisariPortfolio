# Thisari Rathnasekara | Personal Portfolio

A framework-free personal portfolio built from scratch with **HTML5, CSS3 and vanilla JavaScript**.

🔗 **Live site:** https://thisarirathnasekara.github.io/ThisariPortfolio/

## Features

- **Interactive Canvas background**: a grid that ripples with real-time wave distortion as you move the mouse
- **Panel expand effect**: click any nav link and that section grows to fill the viewport
- **3D flip cards** for project reveals (`transform-style: preserve-3d`)
- **Handwritten signature** animation using SVG `stroke-dasharray`
- **Light/Dark theme** via CSS custom properties, saved in `localStorage`
- **Scroll-triggered reveals** with `IntersectionObserver`
- **Cursor trail and glow** effects
- **Real-time SLST clock** in the header
- **Contact form** powered by [Formspree](https://formspree.io) (no backend needed)
- **Hidden easter egg** 🎮 (hint: a famous 1986 cheat code)
- **Responsive** from desktop down to 360px, with landscape and print styles
- **Accessible**: honours `prefers-reduced-motion`

## Tech Stack

HTML5 · CSS3 · Vanilla JavaScript · Canvas API · SVG · Formspree · GitHub Pages

├── myPortfolio.js      # Canvas, interactions, theme, clock, form

## Run Locally

```bash
git clone https://github.com/ThisariRathnasekara/ThisariPortfolio.git
cd ThisariPortfolio
```

Then open `index.html` in your browser. No build step or dependencies required.
